# More reliable score predictions

## Public Summary

Improve how the model learns from historical games so its predictions are better grounded in information available before kickoff.

## Changes

- Freeze team-strength ratings before the first game of each week so forecasts made together cannot use an intervening result.
- Allow qualifying total Locks again, with at most one total and three combined Locks each week.
- Estimate confidence from the distribution of historical score errors, with a firm weekly limit even for high-confidence selections.
- Measure execution-line advantage in the selected pick's direction so an adverse quote cannot become a Lock.
- Train betting confidence on historical forecasts that refresh as earlier games finish, matching the live score-model update process more closely.
- Select how strongly to shrink team-performance inputs using earlier chronological validation games.
- Ignore invalid nonpositive sportsbook totals when determining game eligibility, consensus lines, and market support.
- Apply stronger regularization to score adjustments to reduce sensitivity to noise in historical games.
- Training and validation allow time for earlier games to finish before their scores can inform later predictions.
- Team-strength ratings consistently follow the team whose score is being predicted, for both home and away teams.
- Score predictions start with market-implied team points and learn matchup adjustments from earlier games.
